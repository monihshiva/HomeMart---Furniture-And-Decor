# HomeMart - Furniture & Decor

A frontend-only furniture and home decor e-commerce project for Task WD-EC-004.

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- Product categories and search
- Material and price filters
- Product specifications
- Add to cart and quantity adjustment
- Cart total calculation
- Checkout form
- Simulated payment and delivery scheduling
- Responsive mobile design
- Simple room visualization

## Run
Open `index.html` in a web browser. No database or server is required.
